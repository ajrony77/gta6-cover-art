# Fonts

Two fonts ship with this app, both under the SIL Open Font License (OFL),
both free to use and to ship:

- **Anton** (`Anton-Regular.ttf`) — the heavy condensed capitals of the
  cover title. Copyright 2020 The Anton Project Authors
  (https://github.com/googlefonts/AntonFont). Full license: `OFL-Anton.txt`.
- **Pacifico** (`Pacifico-Regular.ttf`) — the neon script subtitle.
  Copyright 2018 The Pacifico Project Authors
  (https://github.com/googlefonts/Pacifico). Full license: `OFL-Pacifico.txt`.

Both files were taken from the google/fonts repository
(https://github.com/google/fonts/tree/main/ofl), which publishes them under
the OFL. No Rockstar Games font, logo or artwork is used anywhere in this
app: every letter on a cover is set in Anton or Pacifico, and every photo is
an original image-model render or the kit's own free sample.
